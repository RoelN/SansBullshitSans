# Sans Bullshit Sans

Source for the Sans Bullshit Sans font. [Read about how this font was made](http://pixelambacht.nl/2015/sans-bullshit-sans/) or visit the [site](http://www.sansbullshitsans.com/) to see it in action.

This font is based on [Droid Sans](http://www.fontsquirrel.com/fonts/droid-sans) and released under the [Apache 2.0 license](http://www.apache.org/licenses/LICENSE-2.0).

## Installation
Download https://github.com/RoelN/SansBullshitSans/blob/master/SansBullshitSans.ttf and install it into the OS font folder.
  - For Firefox:
    - Tools -> Options -> Content
    - Under 'Font and Colors' select SansBullshitSans
    - Then click 'Advanced' and uncheck `Allow pages to choose their own fonts, instead of my selections above`. This will force SansBullshitSans on every page. Check again to only use SansBullshitSans on websites that haven't specified the font they want to use.
  - For other browsers:
    - similar to above
